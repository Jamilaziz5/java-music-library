# Java Music Library

A text-based music library application I developed for my Intro to Java course. The program allows users to browse songs, search for music, manage their library, and play local audio files.

## Features

- Menu-driven interface for navigating the application
- Search for songs by title
- Browse a music library
- Mark songs as favorites
- Play audio files locally
- Load song information from a JSON file

## Technologies Used

- **Java** – Application logic and user interaction
- **JSON** – Stores song information
- **Gson** – Reads song data into the application
- **Maven** – Project configuration and dependencies

## Project Background

I built this project as part of my Intro to Java coursework to practice working with data structures, file handling, user input, and organizing a larger program.
